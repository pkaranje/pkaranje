## Selected work

- **[lfed-course-recommender](https://github.com/pkaranje/lfed-course-recommender)**: AI-powered course recommendation and Q&A system built on the [Linux Foundation Training & Certification](https://training.linuxfoundation.org/) catalog. Python 3.12, Docker Compose, CI.
- **[ai-video-intelligence-platform](https://github.com/pkaranje/ai-video-intelligence-platform)**: Video summarization pipeline: upload an MP4, extract key frames with FFmpeg, analyze them with a vision model (OpenAI, Gemini or local Ollama), and get a written summary with a timestamped timeline. FastAPI, Dramatiq, Redis, PostgreSQL, Next.js, Docker Compose.
- **[rag-from-scratch](https://github.com/pkaranje/rag-from-scratch)**: Hands-on RAG with LangChain: embeddings, chunking, PDF/DOCX extraction and OCR. Each lesson has an OpenAI and a local Ollama version.
- **[pkaranje.github.io](https://github.com/pkaranje/pkaranje.github.io)**: Personal site, built with Astro.

## Open source

- **[spdx-sbom-generator](https://github.com/opensbom-generator/spdx-sbom-generator)**: SPDX software bill of materials (SBOM) generation for CI. I contributed the Python plugin (Pipenv, Poetry and venv support) and several follow-up fixes, all merged ([#25](https://github.com/opensbom-generator/spdx-sbom-generator/pull/25), [#131](https://github.com/opensbom-generator/spdx-sbom-generator/pull/131), [#133](https://github.com/opensbom-generator/spdx-sbom-generator/pull/133), [#165](https://github.com/opensbom-generator/spdx-sbom-generator/pull/165)).
- **[python_sbom](https://github.com/licquia/python_sbom)**: a pure-Python SBOM generator. I fixed two Windows environment bugs in it ([#1](https://github.com/licquia/python_sbom/pull/1), [#2](https://github.com/licquia/python_sbom/pull/2)), both merged.
- **[serverless-wsgi](https://github.com/logandk/serverless-wsgi)**: the Serverless plugin for deploying WSGI apps (Flask, Django, Pyramid) to AWS Lambda. My [fix for a 404 on request-path handling](https://github.com/logandk/serverless-wsgi/pull/199) was merged upstream.
